# TMA3084 SELAB - Lab 1: Pizza Order Calculator

## Description
A simple Dart program that calculates the total payment for pizza orders using a switch statement and a while loop.

## Pizza Prices
- Small: 5 USD
- Medium: 7 USD
- Large: 10 USD

## Features
- Accepts pizza size and quantity from the user.
- Calculates the total payment.
- Allows continuous ordering.
- Uses the dart:io library for input and output.

```bash
dart main.dart
```
